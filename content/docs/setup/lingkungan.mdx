## Akses serial port

<Tabs items={['Linux', 'macOS', 'Windows']}>
  <Tab value="Linux">
```bash
sudo usermod -aG dialout $USER
# Log out dan log in kembali agar keanggotaan grup berlaku.
```
  </Tab>
  <Tab value="macOS">
```bash
ls /dev/tty.usb*
```
  </Tab>
  <Tab value="Windows">
Buka Device Manager → Ports (COM & LPT), catat nomor COM yang muncul saat board ditancapkan.
  </Tab>
</Tabs>

## Variabel environment

```bash
export LAB_TOOLCHAIN_HOME="$HOME/.lab/toolchain"
export PATH="$LAB_TOOLCHAIN_HOME/bin:$PATH"
```
